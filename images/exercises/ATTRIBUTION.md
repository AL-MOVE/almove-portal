# AL MOVE exercise images

The initial curated exercise images in this directory are derived from
[RepDB's free exercise dataset](https://github.com/RepDB/exercise-dataset).
The RepDB Free Tier License permits commercial use inside applications with a
visible attribution link.

They are delivered locally by `portal.almove.pt`; the client app never requests
an image from the upstream service at runtime. The catalogue mapping is in
`/js/exercise-media.js`. Visible in-app attribution: “Exercise data by
[RepDB](https://repdb.co)”.
